There is a seemingly obvious issue with how AI process files. So to start with, this is on Antigravity IDE, Google's IDE fork of Windsurf. When I prompt AI (whether is it Gemini (Pro or Flash) or the complimentary Claude (Opus or Sonnet)) to read through several files all at once, they seems to only read it briefly without any further thinking, whereas if I were to ask it to read one file, it would go through the file and more importantly, reasons out. Because when it only read the file without any internal reasons, there is a hint, and that it, it's done really fast. 

So what is the different between reading it and reading it and reasoning it out. Or rather, why it is important, I think for my particular use case, it does.

So I was asking it to sorts articles into appropriate topics (Business, Education, Religion) from articles save within folders sorted by author. If the AI only read through the file without reasoning, it can only sort the file to the superficial domain, that is written words within that article accumulatively point to, but not actually the domain that they author were elaborating about. 

For example, an book review of "Lying for Money" is reasonably within the field of finance or economics, but the AI sort it to Society & Culture. Even though there are cultural and societal elements in it, namely how scammer hi-jack trust network to exploit people, it is on a whole, about systems of trust within an economy. But AI sorted it to Society & Culture when prompt to move a batch, within it contains this article, to the appropriate folders.

Compared to when it being asked to specifically read this article and then assign the most suitable domain, it firmly recommend economics or finance. And I suspect because it takes an additional step of reasoning it out. It summarizes the content of the article then use this to reasons why it should be in a particular subject matter and then output parts of these reasons for user to see.

I think this is a symptom of a bigger issue with AI, or rather our perception of AI. We don't understand a fundamental fact that it lacks continuous existence, even instances of AI is a new, extremely intelligent person, who can read the context left by the conversation as well as the file that it read within the conversation.
